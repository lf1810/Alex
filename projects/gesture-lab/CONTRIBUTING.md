# 参与贡献

感谢你愿意改进手势交互实验室。

## 开发流程

1. Fork 本仓库并创建功能分支。
2. 执行 `npm install`。
3. 使用 `npm run dev` 进行本地开发。
4. 提交前运行 `npm test` 和 `npm run build`。
5. 在 Pull Request 中说明改动内容、测试方式和涉及的浏览器。

## 提交问题

请提供浏览器版本、操作系统、复现步骤以及控制台错误。摄像头相关问题请勿上传包含他人面部或私人环境的录屏。

## 代码原则

- 摄像头数据只在浏览器本地处理。
- 新增交互必须提供鼠标或触摸备用操作。
- 动效应尊重 `prefers-reduced-motion`。
- 避免引入不必要的网络请求和大型依赖。
