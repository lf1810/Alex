# 初剪分析标准

初剪只做结构性选择，不代替用户的动效精修。

1. 逐个源文件核对分辨率、帧率、时长和音轨。
2. 优先保留完整语义、结论、证据和自然表情，删除明显口误、重复句、无意义停顿。
3. 不因为“听起来更顺”擅自改动事实数据。
4. 段与段衔接至少保留自然辅音/元音收尾，不能切在发音中间。
5. 同源多段必须使用一个连续时间线计划，避免重叠、倒序和单帧回跳。
6. 每个剪辑点注明：
   - 源文件；
   - 源入点与源出点；
   - 成片入点；
   - 保留/删除原因；
   - 是否需要用户人工复听。
7. 初剪方案不自动添加动效、字幕、音乐或音效。
8. 用户确认后，ProjectDocument 中每个片段仍保持独立可裁切。
