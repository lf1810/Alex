# 萃猫 · cuimao

把一本书、一篇访谈、一份长文档，**蒸馏成 AI 能直接调用的技能包**。

产出的不是读书笔记，不是摘要，而是**能让一个没读过这本书的人，遇到具体问题时直接照着做成一件事的操作指令**。

> 没读过原书也能蒸——萃猫不向你提问，直接把结果给你。

## 它能蒸出什么

| 材料类型 | 蒸出什么 | 用法 |
| --- | --- | --- |
| 工具书（方法论类） | **what they do**——书里的方法，遇到问题直接拿来用 | 调技能解决具体问题 |
| 非工具书（思想类） | **how they think**——作者的思维框架 | 照着思路自己找方法 |

支持的输入：一本书、一篇访谈、一份课程讲稿、一份会议记录、一篇论文，或者一份视频/播客的转写稿。TXT、PDF、Markdown 都行。

## 怎么装

**方式一：丢给 AI 装（推荐）**

把这个仓库打包成 zip，发给你的 AI 助手（WorkBuddy / Claude 等支持 Skill 的工具），说一句：

```
安装这个 Skill
```

**方式二：手动放进去**

把 `SKILL.md` 和 `references/` 一起放进技能目录，例如 WorkBuddy：

```
~/.workbuddy/skills/cuimao/
├── SKILL.md
└── references/
```

## 怎么用

1. 把要蒸馏的内容发给 AI（一本书的电子版、访谈转写稿都行）
2. 说：**「用萃猫，蒸馏它。」**
3. 等它跑完（会产出几个 Skill），再说：**「帮我安装这些 Skill，告诉我怎么用。」**

一次给多份材料也可以，萃猫会先帮你分流哪些能做、哪些不适合做。中途想接着上次的进度，说「继续蒸馏」即可。

## 执行过程

萃猫走固定的七步：**闸门 → 骨架 → 五路提取 → 三重验证 → 归并 → 盲测 → 打包**。

全程自动执行，除了第一步确认材料够不够蒸，中途不向你提问。每完成一步会把进度落到 `状态.md`，所以长任务可以断点续做。

## 目录结构

```
SKILL.md                              主流程与执行总则
references/
├── extractor-framework.md            五路提取框架
├── extractor-principle.md            提取原则
├── extractor-glossary.md             术语口径
├── extractor-case.md                 正例
├── extractor-counterexample.md       反例
├── skeleton-template.md              骨架模板
├── skill-template.md                 技能包模板
└── test-prompts-template.md          盲测题模板
```

## 和「仓颉」怎么选

萃猫的灵感来自 GitHub 上知名的蒸馏 Skill **仓颉**。两者思路相同，门槛不同：

- 这本书你**认真读过、有较深理解** → 用仓颉，效果更好（它会反问你，帮你校准方向）
- 这本书你**没读过 / 不熟** → 用萃猫，它不提问，直接出结果
